# Progress report #4: competitor scan and silent-stream retry (2026-11-25)

Reporting window 2026-11-24 → 2026-11-25 (short window). Main outputs: the
competitor scan owed from report #3, one new harness PR (#334) derived from
it, and acceptance of the six PRs merged 2026-11-24.

## 1. Competitor deltas

Full evidence: `code-research/docs/competitor-scan-2026-11-25.md` (outside
this repo; GitHub releases API, window 2026-11-17 → 11-25).

- **Claude Code v2.1.326–v2.1.331** (anthropics/claude-code/releases):
  retry-once on silent/thinking-only replies; a tool call with no tool name
  now errors and the session continues (contrast: our #321 recovers the name
  from the argument signature instead of erroring — right call for degraded
  local engines); OTel `gen_ai.*` spans; auto-compact XML-tag summary fix.
- **opencode v2.4.0/v2.4.1** (sst/opencode/releases, 2026-11-23):
  `experimental.model_speeds` service tiers; compaction `keep.tokens`
  retention fix; extra-cache-cost-after-compaction fix.
- **goose v1.60.0–v1.60.2** (block/goose/releases, 2026-11-17–20): drop the
  `<analysis>` scratchpad Claude models refuse; keep think tags in Ollama XML
  tool-call arguments (direct analog of our #321/#1694 work); bound empty
  response retries; `final_output` visible only to the model (same pattern
  as our isMeta nudge).

Three takeaways: (1) degenerate-stream retry bounds are table stakes across
all three vendors; (2) compaction fidelity is the hottest shared battleground
— three vendors shipped compaction fixes in one window; (3) local-model
tool-call robustness is an active peer topic (goose's Ollama parser is worth
reading for malformed-argument tolerance).

## 3. Best-practice adoption this window

Scanning takeaway (1) turned into code the same day: **#334 — retry once on
silent fusion-mlx streams** (merged, accepted). `withSilentStreamRetry`
buffers leading non-content events, flushes on first real content (zero
added latency once content flows), and re-issues the request once when the
stream ends with no text and no tool_use; thinking-only counts as silent.
Wired at both fusion-mlx entry points; skipped on the stream-resume path (a
re-issued request gets a new stream id and would invalidate the cursor/state
side-channels). Compaction-scratchpad audit (takeaway 2) is queued, not
started.
